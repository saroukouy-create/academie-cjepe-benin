Comprendre le web comme une maison

Construire un site web, c'est comme construire une maison. Avant de poser la première brique, il faut comprendre les rôles de chaque élément. C'est ce que nous allons faire ensemble dans ce préambule.

🏗️ Les fondations : c'est le sol sur lequel tout repose. Sans fondations solides, la maison s'effondre. En développement web, les fondations sont les langages de base qui structurent, habillent et animent le contenu. Ces trois langages sont HTML, CSS et JavaScript. Ils travaillent ensemble comme une équipe de construction.

HTML

HyperText Markup Language

C'est le squelette de la maison. Il définit les murs, les pièces, les portes et les fenêtres. Sans HTML, il n'y a pas de structure, juste un terrain vide.

Rôle : Structure

CSS

Cascading Style Sheets

C'est la décoration et l'aménagement intérieur. Il donne les couleurs, les textures, la disposition des meubles, et rend la maison agréable à vivre. Sans CSS, la maison est fonctionnelle mais nue et sans style.

Rôle : Présentation

JavaScript

JavaScript (JS)

C'est l'électricité et la plomberie de la maison. Il rend tout interactif : les interrupteurs allument les lumières, les robinets coulent, les portes s'ouvrent. Sans JavaScript, la maison est statique et inerte.

Rôle : Interactivité

En résumé : HTML construit les murs, CSS les peint et les meuble, JavaScript les rend vivants. Ensemble, ils forment une maison numérique fonctionnelle et agréable.

Maintenant que vous comprenez les bases, chaque concept sera expliqué simplement, avec des exemples concrets. Aucune connaissance technique n'est requise.

Module 1 · Fondations Web

coeff. 1
Les bases absolues : comprendre comment fonctionne un site web, de zéro.
HTML, CSS, JavaScript, Git Semaines 1 à 3 Aucun prérequis

HTML

Le squelette d'une page web. C'est le langage qui donne la structure : titres, paragraphes, images, liens...
Exemple : <h1>Bonjour</h1> crée un grand titre.

CSS

Le style et la mise en page. C'est ce qui rend une page belle : couleurs, polices, marges, disposition.
Exemple : color: blue; rend le texte bleu.

JavaScript

Le langage qui rend une page interactive. Il permet de réagir aux clics, de modifier le contenu, de faire des calculs...
Exemple : alert('Bonjour !') affiche une fenêtre pop-up.

Git

Un outil qui sauvegarde l'historique de votre code. Comme une machine à remonter le temps pour vos fichiers.
Exemple : git commit enregistre une version de votre travail.
Livrable : site vitrine responsive versionné Évaluation : projet + quiz (coeff.1)

Module 2 · Front-End avancé

coeff. 2
Construire des interfaces modernes et dynamiques avec des frameworks professionnels.
React, Angular, API Semaines 4 à 6 Prérequis : bases HTML/CSS/JS

React

Un framework JavaScript qui permet de construire des interfaces utilisateur réactives. Il découpe l'écran en "composants" réutilisables.
Exemple : un bouton "J'aime" qui change de couleur lorsqu'on clique dessus.

Angular

Un autre framework (complet) pour créer des applications web. Il utilise TypeScript et structure le code en composants et services.
Exemple : une application de gestion de tâches avec des listes dynamiques.

API REST

Un point d'accès à des données distantes. C'est comme un serveur qui livre des informations sur demande (météo, actualités...).
Exemple : fetch('https://api.meteo.fr') récupère la météo.

Authentification

Le système qui permet à un utilisateur de se connecter avec un email et un mot de passe, et de gérer sa session.
Exemple : un formulaire de connexion avec un bouton "Se connecter".
Livrable : application front-end connectée à une API Projet complet (coeff.2)

Module 3 · Back-End & BDD

coeff. 2
Apprendre à créer des serveurs, des bases de données et des API.
Node.js, PHP, MySQL, MongoDB Semaines 7 à 9 Prérequis : bases JavaScript

Node.js

Un environnement qui permet d'exécuter JavaScript sur un serveur. C'est le "moteur" qui fait tourner le code côté serveur.
Exemple : un serveur qui renvoie "Bonjour" quand on visite une URL.

PHP

Un langage de programmation côté serveur, très utilisé pour créer des sites dynamiques. Il génère du HTML à la volée.
Exemple : <?php echo 'Bonjour'; ?> affiche "Bonjour" sur la page.

MySQL

Une base de données relationnelle. Elle stocke les données dans des tables structurées (comme un tableur avec des colonnes).
Exemple : une table "utilisateurs" avec les colonnes "id", "nom", "email".

MongoDB

Une base de données NoSQL qui stocke les données sous forme de documents JSON. Plus flexible qu'une base relationnelle.
Exemple : { "nom": "Jean", "age": 30 } est un document.
Livrable : API REST sécurisée + documentation Évaluation : API + BDD (coeff.2)

Module 4 · Mobile & Design

coeff. 2
Créer des applications mobiles et maîtriser l'expérience utilisateur.
Flutter, React Native, Figma Semaines 10 à 12 Prérequis : bases JavaScript/React

Flutter

Un framework pour créer des applications mobiles (iOS et Android) avec un seul code. Il utilise le langage Dart.
Exemple : une application de suivi de tâches qui fonctionne sur iPhone et Android.

React Native

Une version de React pour le mobile. Elle permet de créer des applications natives en utilisant les composants React.
Exemple : une application de chat avec des bulles de discussion.

Figma

Un outil de design d'interface. Il permet de créer des maquettes et des prototypes avant de coder.
Exemple : une maquette interactive d'une application mobile avec des écrans et des boutons cliquables.

UX (Expérience utilisateur)

La discipline qui consiste à rendre une application agréable et facile à utiliser. Elle prend en compte les besoins et les émotions des utilisateurs.
Exemple : placer un bouton d'action important en évidence et facilement accessible.

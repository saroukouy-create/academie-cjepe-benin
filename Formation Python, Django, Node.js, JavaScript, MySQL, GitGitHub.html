  2. écris une fonction salaire_total(employes) qui retourne la somme des salaires.
  3. écris une fonction trier_par_salaire(employes) qui retourne la liste triée par salaire décroissant.
  4. Affiche chaque employé avec print au format : Nom - Salaire FCFA.
  5. Bonus : affiche uniquement les employés dont le salaire dépasse 300000.
Résultat attendu : la liste des employés triée du plus gros au plus petit salaire, puis le salaire total affiché, puis la liste filtrée en bonus.
Solution
employes = [
 {"nom": "Alice", "salaire": 450000},
 {"nom": "Bob", "salaire": 280000},
 {"nom": "Chantal", "salaire": 520000},
 {"nom": "David", "salaire": 310000},
]

def salaire_total(employes):
 return sum(e["salaire"] for e in employes)

def trier_par_salaire(employes):
 return sorted(employes, key=lambda e: e["salaire"], reverse=True)

for e in trier_par_salaire(employes):
 print(f"{e['nom']} - {e['salaire']} FCFA")

print(f"Salaire total : {salaire_total(employes)} FCFA")

# Bonus
print("Employés > 300000 :")
for e in employes:
 if e["salaire"] > 300000:
 print(e["nom"])

🛠️ TP JavaScript : Formulaire de contact validé

Durée estimée : 40-50 min

Objectif : manipuler le DOM et les événements pour valider un formulaire côté client.

Consignes :

  1. Crée un formulaire HTML avec deux champs : nom et email, et un bouton "Envoyer".
  2. écoute l'événement submit du formulaire en JavaScript.
  3. Empêche l'envoi par défaut avec event.preventDefault().
  4. Vérifie que le champ nom n'est pas vide et que l'email contient un @.
  5. Affiche un message de succès ou d'erreur dans une zone <div id="message">.
Résultat attendu : si les champs sont valides, un message vert "Merci [nom], formulaire envoyé !" s'affiche. Sinon, un message rouge indique l'erreur.
Solution
const form = document.getElementById('contactForm');
const message = document.getElementById('message');

form.addEventListener('submit', (event) => {
 event.preventDefault();
 const nom = document.getElementById('nom').value.trim();
 const email = document.getElementById('email').value.trim();

 if (nom === '' || !email.includes('@')) {
 message.textContent = "Erreur : vérifie le nom et l'email.";
 message.style.color = 'red';
 return;
 }

 message.textContent = `Merci ${nom}, formulaire envoyé !`;
 message.style.color = 'green';
});

🛠️ TP Node.js : Mini API Employés (Express)

Durée estimée : 45-60 min

Objectif : créer une API REST avec Express pour gérer une liste d'employés en mémoire.

Consignes :

  1. Initialise un projet avec npm init -y et installe express.
  2. Crée un tableau employes en mémoire avec quelques employés (id, nom, salaire).
  3. Crée une route GET /api/employes qui retourne la liste complète en JSON.
  4. Crée une route GET /api/employes/:id qui retourne un employé précis.
  5. Crée une route POST /api/employes qui ajoute un nouvel employé (via express.json()).
Résultat attendu : avec Postman ou le navigateur, GET /api/employes renvoie un tableau JSON, et un POST avec un corps JSON ajoute un employé consultable ensuite.
Solution
const express = require('express');
const app = express();
app.use(express.json());

let employes = [
 { id: 1, nom: "Alice", salaire: 450000 },
 { id: 2, nom: "Bob", salaire: 300000 },
];

app.get('/api/employes', (req, res) => {
 res.json(employes);
});

app.get('/api/employes/:id', (req, res) => {
 const employe = employes.find(e => e.id === parseInt(req.params.id));
 if (!employe) return res.status(404).json({ erreur: "Employé introuvable" });
 res.json(employe);
});

app.post('/api/employes', (req, res) => {
 const nouvel = { id: employes.length + 1, ...req.body };
 employes.push(nouvel);
 res.status(201).json(nouvel);
});

app.listen(3000, () => console.log('API sur port 3000'));

}

def calculate_payroll(salaire_brut):
 cnss_employe = salaire_brut * 0.045
 irpp = 0
 if 300000 < salaire_brut <= 1000000:
 irpp = salaire_brut * 0.05
 elif salaire_brut > 1000000:
